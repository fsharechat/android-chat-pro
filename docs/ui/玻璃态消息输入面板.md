# Android 玻璃态消息输入面板

2026-11-14。设计见 `docs/superpowers/specs/2026-11-14-liquid-glass-message-composer-design.md`。

## 实现与边界

- Java/XML 保持原技术栈与 minSdk21 / compileSdk29。子页面 Tab 无既有问题，按用户要求不改动相关导航。
- 默认“＋”圆框与单行输入胶囊实测均为48dp、顶部对齐，间距8dp。内部按钮保留48dp点击范围，发送图形16dp、键盘图形20dp、表情图形22dp。文字和占位提示垂直居中，多行及系统大字体按内容增长。
- ＋常驻；有正文时尾部为发送，空正文为语音。更多中新增“语音消息”，允许保留正文后切换录音。Emoji/更多/键盘互斥，切换不重建Editable，保留正文、选区及MentionSpan。
- 浅色使用灰蓝承托与可见边界，深色使用独立材质颜色。`ComposerGlassView`共用一份背景采样绘制圆框和胶囊，采样源仅消息列表，不采输入控件。
- `GlassBackdropRenderer.Target`隔离背景接收方，原首页`GlassTabBar`沿用相同渲染器。保留CaptureCanvas与GlassEdgeEffectFactory隔离，消息列表也接入同一机制，防止离屏采样干扰滚动回弹。
- 会话页改为覆盖布局，列表底部留白按实际输入面板高度计算，键盘由窗口adjustResize处理；不再重复叠加键盘高度。阅读历史时保留可见位置，跟随底部时保持最新消息可见。
- `InputAwareLayout`对异步回调校验转移编号，取消之后的旧键盘回调不能重新弹出面板。横向键盘高度单独保存。只修改会话页的窗口resize策略，不修改全应用系统栏策略。
- 点击/拖动消息区收起键盘与自定义面板，返回键先收起输入再退出。选择附件返回后正文保留，不修改现有多图选择、拍摄视频、文件、位置、贴纸和通话实现。
- 草稿使用`Draft.parseDraft`恢复@身份；坏JSON及越界span安全忽略，保存时比较序列化草稿，避免只比较文字而漏掉@元数据变化。
- `RecordingGesture`将系统取消和普通松手区分；64/44dp阈值提供上滑取消/回滑恢复的滞回。60秒超时只消费一次结果；取消不发送，临时文件删除。录音结束、退后台、离页和焦点中断统一释放MediaRecorder、音频焦点、Handler任务与弹层。权限完成后须重新按住，不自动开始过期手势。
- 文件编码仍为AMR_NB；沿用现有发送、上传和输入状态信令。没有修改服务端、proto、数据库或Android子页面Tab。
