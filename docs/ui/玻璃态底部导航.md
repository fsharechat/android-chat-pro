# 玻璃态底部导航

参考同级 iOS 工程 `App/GlassTabBar.swift`，Android 保留 Java/XML、ViewPager 和原有三个首页 Fragment。

## 结构与参数

- `GlassTabBar`：62dp 高，左右边距 20dp，最大宽度 420dp，距离应用内容区底部 8dp。当前窗口由系统保留导航栏区域，底栏无需重复累加系统导航栏高度。
- `GlassBackdropRenderer`：采样 ViewPager，不包含底栏；向外多采样 16dp，按 1/8 分辨率处理，三次可分离盒式模糊后裁剪为胶囊。
- 页面在底栏后方继续绘制。会话、联系人列表以及“我的”滚动容器增加 82dp 底部留白，让末项能滚到胶囊上方。
- 颜色、尺寸和文案集中在 `values/glass_tab.xml`，深色材质覆盖在 `values-night/glass_tab.xml`。

## 交互与生命周期

- 页面横滑通过 `onPageScrolled(position + offset)` 同步底栏连续位置。
- 底栏按住拖动预览选中块，松手选择最近的 Tab；取消回到实际选中项。
- 弹簧统一驱动位置、速度拉伸和按下缩放；按下目标缩放为 1.12。页面跟手时直接更新位置。
- 图标、文字按连续位置插值颜色；角标固定在图标右上角，99 以上显示 99+。
- 触摸以外的点击由各 Tab 的可访问按钮处理，并提供选中状态和未读数描述。
- 模糊在独立单线程运行，复用位图和像素缓冲；最高约 30 次/秒，采样加模糊耗时超过 24ms 时降低刷新频率。页面静止时停止采样。
- Activity 停止时移除采样监听、复位手势；销毁时释放位图和关闭线程。

## 边界滑动跳动修复（2026-11-08）

现象：会话列表到顶或到底后继续拖动时，边缘拉伸反复被打断，内容发生跳动。

定位：真机录屏可重复捕获拖动中的反复方向反转。保持模糊任务调度不变、仅跳过 `source.draw(canvas)` 的诊断包不再出现该现象，用户也确认诊断包上下滑动已恢复正常。根因是离屏采样重复进入了同一份列表边缘效果的有状态绘制链路。

修复：模糊采样使用带标记的 `CaptureCanvas`；首页会话和联系人 RecyclerView 使用 `GlassEdgeEffectFactory`，遇到该采样 Canvas 时跳过 EdgeEffect 绘制。真实屏幕绘制仍调用系统实现，保留正常回弹，模糊采样也恢复开启。不要通过关闭全部 overscroll 或永久关闭模糊绕过这一问题。

回归方式：在同一台魅族 20 上，页面稳定后分别持续下拉、持续上划、再次下拉；录屏跟踪同一会话图标位置，区分正常的一次拉伸/释放与拖动中的反复回跳。该症状依赖真机 EdgeEffect 状态，普通 JVM 模糊算法测试无法覆盖它。

正式修复包 `:chat:assembleDebug --offline` 构建通过并已覆盖安装。相同手势录屏中，修复前一秒内可检测到 3 次反复回跳，修复后为正常拉伸/释放产生的 1 次方向反转，通过回归判定；已检查修复后画面，玻璃底栏与正常系统拉伸同时保留。

版本已升级为 2.0.21（versionCode 20021），Debug 构建通过，覆盖安装到魅族 20 后已核对版本号并启动应用，保留原有应用数据。
